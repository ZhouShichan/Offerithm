## 测试与可复现步骤

使用 Node.js 20.20.0，当前机器 Chromium。新增 `@playwright/test` 1.56.1 为开发依赖并更新锁文件；没有新增运行时依赖。默认使用 Playwright 管理的 Chromium，云环境可通过环境变量指定已安装的浏览器。

```bash
npm ci
npm test
npm run typecheck
npm run lint
npx playwright install chromium
npm run test:e2e
```

已有系统 Chromium 的机器可将最后两步换成：

```bash
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:e2e
```

`test:e2e` 自动为根与子路径各构建一次，并启动三个独立服务：4273 的 Pages 生产预览、4274 的根路径生产预览、5273 的存储模块开发服务；测试结束自动关闭。测试强制各自的 base，不依赖用户的 `VITE_BASE` 设置；已用 `VITE_BASE=/custom/` 验证这一点。存储测试从 Vite 加载实际 `db.ts`，在隔离浏览器上下文中拦截真实 IndexedDB 请求事件，不接触用户浏览器数据。
